分析日期：2026-06-10

视频时长：约 7 分 48 秒

## 一、结论

这个软件不是传统时间线剪辑器，而是一个“短视频批量生成工作台”。

它的核心能力是：

1. 批量导入视频素材。
2. 自动或手动分割视频片段。
3. 给片段套效果、裁剪、转场、调色、去重。
4. 批量生成文案。
5. 文案转语音。
6. 自动生成字幕。
7. 配置字幕样式。
8. 加背景音乐。
9. 去水印或处理水印。
10. 批量导出短视频成片。

它真正卖点不是“剪辑很专业”，而是“把大量素材快速变成大量短视频”。

## 二、视频中看到的功能模块

### 0. 账号、会员和 API Key 体系

补充截图显示，这个软件还有一套商业化和 API 接入体系。

用户中心里有：

1. 个人信息。
2. 邮箱。
3. 有效期。
4. 普通用户 / 会员身份。
5. 卡密兑换。
6. 修改密码。
7. 退出登录。

API Key 页面里有：

1. 平台选择。
2. 火山引擎。
3. Ark API Key。
4. TTS API Key。
5. 保存按钮。

页面说明：

```text
Ark API Key：用于 AI 文案匹配与素材理解
TTS API Key：用于语音合成，同时作为 ASR 的 AppKey
```

这个信息非常关键。

它说明 EcutPro 的架构不是“软件商自己承担全部 AI 成本”，而是：

```text
软件授权收费 + 用户自己填写火山引擎 API Key + 本地批量处理
```

也就是说：

1. 软件本身通过会员或卡密控制使用权限。
2. AI 文案理解和素材匹配走火山方舟 Ark。
3. 语音合成和可能的语音识别走豆包语音 / 火山语音。
4. 用户自己的 API Key 承担模型调用成本。
5. 软件主要卖工作流、界面、批处理能力和本地渲染能力。

这是一种很适合个人开发者模仿的商业结构：

```text
桌面软件卖授权
AI成本由用户自己的云服务账号承担
开发者不需要垫付大量模型费用
```

首页标题是“智能视频批量处理工作站”。

主要功能入口：

| 功能 | 视频中看到的定位 | 对我们是否重要 |
|---|---|---|

| 视频效果处理 | 批量加特效、去水印、加文字、加图片、视频水印等 | 中 |

## 三、它的本质架构

这个软件可以拆成 5 层：

| 层级 | 作用 | 我们可以怎么做 |
|---|---|---|
| 素材层 | 导入、扫描、预览、分类、分割 | 用 ffprobe + 本地文件管理实现 |
| 策略层 | 随机组合、AI 匹配、分类混剪、去重参数 | 用 JSON 生成剪辑计划 |
| AI 层 | 文案生成、文案改写、语音合成、字幕 | 接 OpenAI / DeepSeek / Edge-TTS / Whisper |
| 渲染层 | 裁剪、拼接、字幕、音频、转场、导出 | 用 FFmpeg 实现 |
| 工作台层 | 批量任务、参数配置、预览、进度日志 | 用 React + FastAPI + Tauri 实现 |
| 授权层 | 登录、会员、卡密兑换、有效期校验 | 先本地授权，后续再接云端授权服务 |
| API配置层 | 火山方舟 Ark、豆包语音 TTS/ASR Key 管理 | 本地加密保存用户自己的 Key |

## 五、推荐蒸馏路线

| 功能 | 推荐参考 |

| 自动短视频生成流水线 | MoneyPrinterTurbo |

## 六、我们自己的 MVP 应该怎么做

第一版不要做成完整剪辑软件。

第一版只做 8 个核心功能：

1. 导入一个素材文件夹。
2. 扫描视频文件并显示列表。
3. 自动按固定时长或静音/场景切片。
4. 输入或生成一段文案。
5. 生成配音和字幕。
6. 从素材片段随机组合并导出一个竖屏短视频。
7. 支持填写火山方舟 Ark API Key。
8. 支持填写火山语音 TTS API Key。

第二版再加：

1. 批量生成多个视频。
2. 多文案版本。
3. 字幕样式配置。
4. 背景音乐。
5. 画面缩放、裁剪、变速、镜像等去重参数。
6. 任务队列和日志。
7. 会员状态和卡密兑换页面。

第三版再加：

1. AI 根据文案自动匹配素材。
2. AI 内容提炼。
3. 分类混剪。
4. 多账号短视频矩阵导出规范。
5. 云端授权服务。
6. 用户使用量统计。

## 七、最终判断

网上有现成开源项目可以蒸馏，但没有一个能直接完整替代 EcutPro。

最适合直接拿来研究的组合是：

1. MoneyPrinterTurbo：学短视频自动生成流水线。
2. FunClip：学 ASR、字幕时间戳、AI 片段裁剪。
3. pyVideoTrans：学字幕、配音、TTS、多模型接入。
4. auto-editor：学自动切片和剪辑决策。
5. KrillinAI：学 Agent 化、分阶段任务流水线。

我们自己的产品方向应该是：

```text
本地素材库批量混剪 + AI文案/配音/字幕 + FFmpeg批量导出 + Tauri桌面端
```

这条路线和视频里的 EcutPro 最接近，也最适合长期蒸馏。

## 八、火山引擎接入判断

### Ark API Key

火山方舟 Ark 适合负责：

1. 文案生成。
2. 文案改写。
3. 根据文案理解素材。
4. 给素材片段生成标签。
5. 生成混剪计划 JSON。

推荐默认配置：

```text
平台：火山引擎
Base URL：https://ark.cn-beijing.volces.com/api/v3
接口形态：OpenAI-compatible chat/completions
Key 类型：Ark API Key
```

### TTS API Key

豆包语音 / 火山语音适合负责：

1. 文案转语音。
2. 不同音色选择。
3. 语速和音量控制。
4. 后续可能接 ASR 语音识别。

注意：

Ark API Key 和 TTS API Key 不应该混为一个字段。

推荐拆成：

```text
ark_api_key
ark_base_url
ark_model
tts_api_key
tts_voice
tts_speed
tts_volume
```

### 授权系统

截图里的“卡密兑换”和“有效期”说明它有会员授权体系。

我们可以合法蒸馏这种商业结构，但不能做破解、绕过或复制它的授权服务。

推荐做自己的授权系统：

1. 本地免费试用。
2. 卡密激活。
3. 有效期校验。
4. 到期提醒。
5. 后续接云端授权接口。

第一版可以先只做界面和本地状态，不急着做真正支付系统。
