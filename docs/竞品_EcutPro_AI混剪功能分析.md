## 一、结论

这个软件不是传统时间线剪辑器，而是一个“短视频批量生成工作台”。

它的核心能力是：

1. 批量导入视频素材。
2. 自动或手动分割视频片段。
3. 给片段套效果、裁剪、转场、调色、去重。
4. 批量生成文案。
5. 文案转语音。
6. 自动生成字幕。
7. 配置字幕样式。
8. 加背景音乐。
9. 去水印或处理水印。
10. 批量导出短视频成片。

它真正卖点不是“剪辑很专业”，而是“把大量素材快速变成大量短视频”。

## 二、视频中看到的功能模块

### 1. 首页功能中心

首页标题是“智能视频批量处理工作站”。

主要功能入口：

| 功能 | 视频中看到的定位 | 对我们是否重要 |
|---|---|---|
| AI智能混剪 | 输入文案，AI 从素材中匹配合适片段，生成混剪视频 | 高 |
| 视频效果处理 | 批量加特效、去水印、加文字、加图片、视频水印等 | 中 |
| 视频混剪 | 多文件夹素材混剪，支持随机打乱重组 | 高 |
| 分类混剪 | 按分类文件夹自动组合视频 | 高 |
| 文案改写 | 对已有文案做 AI 改写 | 中 |
| 视频内容提炼 | 从视频中提炼标题、内容、文案等 | 高 |

### 2. 素材导入

视频里演示了导入文件夹。

界面左侧会出现大量 `.mp4` 素材文件列表。

关键点：

1. 支持批量导入。
2. 支持按文件夹管理。
3. 支持输出路径配置。
4. 每个视频可以单独预览。

### 3. 批量片段处理

底部能看到与分段有关的参数，例如：

1. 视频分割。
2. 片头片尾。
3. 抽帧比例。
4. 分镜片段。
5. 批量处理按钮。

这说明它会先把原始视频拆成很多小片段，再从片段中组合成新视频。

### 4. 右侧视频效果模块

右侧面板看到的效果入口包括：

1. 音频设置。
2. 视频封面。
3. 入场效果。
4. 视频旋转。
5. 画中画。
6. 画面调整。
7. 原视频混合。
8. 旋转镜像。
9. 视频变速。
10. 动态缩放。
11. 片尾与水印。

这些功能主要用于“去重”和“批量变体生成”。

也就是说，同一批素材可以通过裁剪、缩放、旋转、调速、画面调整，生成看起来不完全一样的视频。

### 5. AI 文案区

视频中能看到“视频文案”区域，并且有多个文案标签：

```text
文案1
文案2
文案3
文案4
文案5
```

说明一个素材或一个成片任务可以绑定多组文案。

关键点：

1. 支持输入文案。
2. 支持 AI 生成或 AI 改写文案。
3. 支持多个文案版本。
4. 文案会被用于字幕和配音。

### 6. 语音合成

右侧能看到“语音合成”开关，以及声音角色，例如“小何 2.0”。

可调参数包括：

1. 音量。
2. 语速。
3. 随机音色。
4. 声音选择。

这说明它内置或接入了 TTS 配音服务。

### 7. 字幕样式

右侧能看到“文字/字幕样式”配置：

1. 字体。
2. 字号。
3. 字体粗细。
4. 描边。
5. 字体透明度。
6. 字体颜色。
7. 描边颜色。
8. 多种颜色预设。

这是短视频批量生成软件的高频刚需。

### 8. 音频和背景音乐

右侧有：

1. 原视频音量。
2. 背景音乐开关。
3. BGM 音量。
4. 音频设置。

说明它支持保留原声、降低原声、添加 BGM、叠加配音。

### 9. 预览和导出

中间区域是视频预览。

能看到字幕叠加在画面上，也能看到成片任务按钮。

推测导出流程：

1. 导入素材。
2. 分割素材。
3. 配置文案。
4. 配置配音。
5. 配置字幕。
6. 配置画面效果。
7. 生成任务。
8. 批量导出。

## 三、它的本质架构

这个软件可以拆成 5 层：

| 层级 | 作用 | 我们可以怎么做 |
|---|---|---|
| 素材层 | 导入、扫描、预览、分类、分割 | 用 ffprobe + 本地文件管理实现 |
| 策略层 | 随机组合、AI 匹配、分类混剪、去重参数 | 用 JSON 生成剪辑计划 |
| AI 层 | 文案生成、文案改写、语音合成、字幕 | 接 OpenAI / DeepSeek / Edge-TTS / Whisper |
| 渲染层 | 裁剪、拼接、字幕、音频、转场、导出 | 用 FFmpeg 实现 |
| 工作台层 | 批量任务、参数配置、预览、进度日志 | 用 React + FastAPI + Tauri 实现 |

## 四、可蒸馏的开源项目

### 1. MoneyPrinterTurbo

地址：

```text
https://github.com/harry0703/MoneyPrinterTurbo
```

适合蒸馏：

1. 主题生成短视频。
2. 自动生成文案。
3. 自动找素材。
4. 自动生成字幕。
5. 自动添加背景音乐。
6. 批量生成视频。

适合程度：高

注意：

它更偏“从主题生成视频”，不是“从本地素材库批量混剪”。

### 2. FunClip

地址：

```text
https://github.com/modelscope/FunClip
```

适合蒸馏：

1. 视频语音识别。
2. 根据字幕时间戳裁剪视频。
3. LLM 辅助选取片段。
4. 多段剪辑。
5. 输出字幕。

适合程度：高

注意：

它更偏“从长视频里找精彩片段”，不是“多素材随机混剪”。

### 3. pyVideoTrans

地址：

```text
https://github.com/jianchang512/pyvideotrans
```

适合蒸馏：

1. ASR 语音识别。
2. 字幕生成。
3. 翻译。
4. TTS 配音。
5. 音视频同步。
6. 多模型、多供应商配置。

适合程度：中高

注意：

它更偏视频翻译和配音。功能思路很值得参考，但要注意许可证和代码复用边界。

### 4. auto-editor

地址：

```text
https://github.com/WyattBlue/auto-editor
```

适合蒸馏：

1. 静音检测。
2. 运动检测。
3. 自动切掉无效片段。
4. 导出剪辑片段。
5. 导出给其他剪辑软件使用的时间线。

适合程度：中

注意：

它是命令行工具，不是完整工作台。但它的自动剪辑决策逻辑很值得借鉴。

### 5. KrillinAI

地址：

```text
https://github.com/krillinai/KrillinAI
```

适合蒸馏：

1. 下载视频。
2. 语音转文字。


## 五、推荐蒸馏路线

不要直接照搬某一个开源项目。

推荐组合：

| 功能 | 推荐参考 |
|---|---|
| 自动短视频生成流水线 | MoneyPrinterTurbo |
| 本地素材分割和片段时间戳 | FunClip + auto-editor |
| 字幕、配音、TTS、ASR | pyVideoTrans + KrillinAI |
| FFmpeg 渲染 | MoneyPrinterTurbo + FFmpeg 官方能力 |
| 工作台 UI | 当前项目 React 前端 + 参考 EcutPro 布局 |
| 桌面端 | 当前项目 Tauri |

## 六、我们自己的 MVP 应该怎么做

第一版不要做成完整剪辑软件。

第一版只做 6 个核心功能：

1. 导入一个素材文件夹。
2. 扫描视频文件并显示列表。
3. 自动按固定时长或静音/场景切片。
4. 输入或生成一段文案。
5. 生成配音和字幕。
6. 从素材片段随机组合并导出一个竖屏短视频。

第二版再加：

1. 批量生成多个视频。
2. 多文案版本。
3. 字幕样式配置。
4. 背景音乐。
5. 画面缩放、裁剪、变速、镜像等去重参数。
6. 任务队列和日志。

第三版再加：

1. AI 根据文案自动匹配素材。
2. AI 内容提炼。
3. 分类混剪。
4. 多账号短视频矩阵导出规范。

## 七、最终判断

网上有现成开源项目可以蒸馏，但没有一个能直接完整替代 EcutPro。

最适合直接拿来研究的组合是：

1. MoneyPrinterTurbo：学短视频自动生成流水线。
2. FunClip：学 ASR、字幕时间戳、AI 片段裁剪。
3. pyVideoTrans：学字幕、配音、TTS、多模型接入。
4. auto-editor：学自动切片和剪辑决策。
5. KrillinAI：学 Agent 化、分阶段任务流水线。

我们自己的产品方向应该是：

```text
本地素材库批量混剪 + AI文案/配音/字幕 + FFmpeg批量导出 + Tauri桌面端
```

这条路线和视频里的 EcutPro 最接近，也最适合长期蒸馏。
